These assets are separate from skill-specific packs such as:


## Brand Approach

The Millie family uses a warm:

```text
Red → Orange → Yellow
```

visual gradient.

The platform assets are **neutral compatibility marks**, not official logos. This avoids implying endorsement or redistributing third-party trademarks as if they were Millie-owned artwork.
