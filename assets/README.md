# Millie Fix Assets

This folder contains the SVG assets referenced by the Millie Fix README.

## Structure

```text
assets/
├── brand/
├── banners/
├── icons/
└── brands/
```

### `brand/`
Original Millie-family branding assets.

### `banners/`
Original decorative README banners.

### `icons/`
Original lightweight functional SVGs created for Millie Fix.

### `brands/`
Neutral compatibility badges for Claude, Antigravity, VS Code, Copilot, Codex, and GitHub.

These compatibility badges are **not official vendor logos**. They intentionally use neutral
letter marks so the repository does not misrepresent vendor trademarks or imply endorsement.

If you prefer official product logos, replace these files with appropriately licensed official
assets while keeping the same filenames used by the README.

## Usage

Example:

```html
<img src="./assets/icons/network.svg" width="27" align="center" alt="" />
```

All SVGs are standalone and require no external font or image files.
