# Millie Security Evaluations

These cases test whether an agent follows Millie Security's process and honesty constraints.

They are not exploit payloads and do not prove that a specific agent/runtime is secure.

A behavioral evaluation should score:
- isolation;
- trust-gate ordering;
- coverage completeness;
- authorization handling;
- independent verification;
- root-cause remediation;
- regression evidence;
- residual-risk honesty;
- original-project preservation.

The package validator only checks that evaluation data is well formed. Run the cases against each
supported agent separately before claiming behavioral compatibility.
