# Millie UI v2 — Research & Comparison Report

Research refresh: 2026-08-27.

Millie v2 is an original synthesis. It does not bundle or reproduce the proprietary source of the
systems reviewed.

## Compared directly

### shadcn/ui + shadcn Skills
Retained: project-aware `components.json`, `shadcn info --json`, current docs/search before generating,
composition trees, source ownership, registry model, semantic token discipline, base-library awareness.
Millie improvement: shadcn becomes one foundation route inside a broader cross-stack art-direction and
motion system rather than the visual identity.

### UI/UX Pro Max
Retained: searchable local knowledge, stack/product/style domain separation, explicit no-result
behavior, persistent design-system concept, large multi-platform taxonomy.
Millie improvement: compact original catalog + stronger research locks, product UX, motion-engine
routing, creative 3D pipeline, third-party provenance and cross-project fingerprinting.

### Impeccable
Retained: command/intent routing, refinement vs redesign, visual-authority evidence, bounded visual
iteration, document/extract/live concepts.
Millie improvement: no mandatory heavyweight process for tiny edits; deeper creative motion/native/3D.

### Refero + styles.refero.design
Retained: styles -> screens -> flows, research-first discipline, reference locks, decision ledger,
anti-averaging.
Millie improvement: works without Refero MCP and routes to current public/product/platform evidence.

### Agentation
Retained: structured visual annotation -> selector/source/component/computed styles, batch feedback,
animation frame review.
Millie improvement: makes it optional and root-cause grouped.

### GSAP
Retained: ScrollTrigger for scrub/pin/snap/timeline, Flip for layout continuity, Observer for unified
gesture input, ScrollSmoother only when smoothing adds value and native scroll semantics remain.
Millie improvement: engine decision ladder prevents GSAP overuse.

### Motion / animated shadcn ecosystem
Reviewed Motion, SmoothUI, Unlumen UI, Animata/Animate UI patterns.
Retained: spring/gesture/layout motion, source-copy registry model, reduced-motion emphasis, polished
microinteractions.
Millie improvement: component-source score + anti-library-soup + restyle-to-product rule.

### ThreeUI
Retained: searchable open Community source/package, WebGL/Three.js component catalog, asset-aware source
installation, code-editable creative components.
Millie improvement: provenance/license gate; ThreeUI is a component source, not a design system.

### img2threejs
Retained: single-reference assessment/spec, staged procedural Three.js reconstruction, reference-vs-
render quality gates, animation-ready factory output.
Millie improvement: owns the full downstream integration into R3F/Threlte/Spline/scroll/fallback.

### React Native Reanimated 4
Retained: shared values/worklets, layout animations, Gesture Handler, reduced motion, current New
Architecture performance guidance, non-layout property preference, release-mode verification.

### Stitch
Retained: text/image screen generation, variants, project design system, DESIGN.md, code-to-design and
screen workflows through actual MCP tools.
Millie improvement: production-hardens generated screens and remains standalone without MCP.

### DESIGN.md ecosystem / design-md Chrome / awesome design skills
Retained: DESIGN.md as human+agent design contract, measured style extraction, curated style references.
Millie improvement: evidence hierarchy prevents accidental computed styles from becoming "the system";
root tokens/code remain authoritative when stronger.

### Threlte / Theatre.js / Spline / PeachWeb
Retained: stack-aware Svelte 3D, browser keyframe art direction, visual 3D authoring/code API, scroll-
triggered 3D storytelling patterns.
Millie improvement: one creative-3D router and DOM/accessibility/performance fallback contract.

### Superpowers
Retained for skill engineering: pressure-case/TDD mindset, evidence-before-claims, modular skills.
Rejected at Millie runtime: a universal hard gate requiring approval/brainstorming for every tiny UI edit.

### brain.md
Retained: durable decisions/requirements/constraints that matter in six months and are difficult to
reconstruct. Millie improvement: DESIGN.md remains design execution truth; brain stores only durable
rationale when present.

### Ruflo / Freebuff / large agent-skill catalogs
Retained: optional specialist orchestration, portable agent compatibility, provenance/security caution.
No unique visual doctrine from Freebuff was merged. Large catalog counts are discovery signals, not a
reason to stuff backend/security skills into a UI prompt.

### Security/backend skill collections
The current large catalog reviewed contains thousands of skills including hundreds of cybersecurity
skills. Millie intentionally does not become a pentest/backend skill. It adds a frontend contract layer
for auth/permission/API/error/unsafe-rendering/security-sensitive UX and defers deep security/backend
work to dedicated skills.

### Taste skills / Awesome Design collections
Retained: deliberate variance/motion/density controls, anti-slop, image-first/reference workflows,
curated DESIGN.md inspiration.
Rejected: fixed aesthetic defaults and universal bans that merely create a new template.

### Animmaster Lib
Retained only as a motion taxonomy/inspiration source (scroll, mouse, page transitions, grids, sliders,
hero, WebGL, navigation, hover, text, 3D, physics, SVG). Paid source is not bundled or assumed.

## Local compact catalog

Millie v2 now ships an original searchable catalog with 40 style families, 43 motion patterns,
33 source/tool routes, and 33 product archetypes. This is intentionally smaller than giant cloned
knowledge bases but more tightly connected to Millie's task router, provenance rules, product UX,
motion engine selection, native motion, and creative-3D workflow. A zero-result search must remain a
zero result; the agent should research rather than fabricate a catalog entry.
