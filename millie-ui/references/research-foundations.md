# Millie UI — Research Foundations

Research refresh: August 26, 2026.

Millie is an original synthesis. It is not a copy of a single public skill, design system, or
showcase website.

## Agent Skills Reviewed

Research included current public frontend/UI skill approaches such as:
- Anthropic-style frontend design skills
- PracticalSwan Frontend Design
- mblode UI Design and UI Animation
- Impeccable-derived frontend design skills
- animation-focused Agent Skills
- other current UI/UX Agent Skill repositories

Patterns retained:
- commit to art direction
- prevent generic AI defaults
- context-fit beats one universal style
- rendered verification
- motion as state passage, not decoration
- accessibility/performance as hard gates

Millie adds:
- a deeper style catalog
- product-archetype mapping
- no-direction Auto Premium Mode
- cross-project Design Fingerprints
- deterministic diversity fallback
- palette-generation logic
- motion/3D selection rules
- explicit style implementation recipes

## Current Platform Guidance

Research included:
- Apple Human Interface Guidelines and current Liquid Glass guidance
- Android/Material adaptive window guidance
- WCAG 2.2
- MDN accessibility, filters, modern CSS, performance
- current web responsive/container-query practices

Key conclusion:
material effects such as glass should communicate hierarchy and layering, not cover every surface.

Research included contemporary guides/discussions for:
- glassmorphism

- neobrutalism
- editorial design
- modern 2026 UI/web design trends

Key conclusion:
named styles are useful vocabulary, but style choice changes implementation, accessibility budget,
motion budget, component geometry, and performance.

## Community Criticism

Recurring concerns:
- AI-generated pages are visually coherent but repetitive
- "premium" collapses into dark gradients/glass
- animation is frequently added without interaction value
- Awwwards-style experiences can prioritize spectacle over access
- pure neumorphism has structural affordance/contrast problems
- glass can fail under unpredictable backgrounds
- 3D becomes harmful when it blocks content or performs poorly

Millie converts these into explicit gates.

## Refresh Rule

For a high-visibility creative project, refresh research when browsing exists.
Do not assume this 2026 snapshot remains trend-current forever.
