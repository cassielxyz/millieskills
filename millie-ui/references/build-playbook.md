# Build Playbook

## Sequence

1. Read product/surface context.
2. Classify surface mode.
3. Inspect existing visual authority.
4. Resolve UX structure and reachable states.
5. Choose/derive art direction.
6. Establish compact design tokens.
7. Implement semantic functional skeleton.
8. Add visual hierarchy.
9. Add purposeful motion/signature detail.
10. Harden content/states/accessibility.
11. Render one batched verification round.
12. Fix as one consolidated pass.
13. Confirm once.

## Existing page

Preserve product truth and existing components unless the task explicitly authorizes redesign.

## Complexity rule

Match implementation complexity to the vision.

A minimal visual direction can be difficult because spacing/type/detail must be exact.
A maximal/immersive direction can justify more implementation only if the product can afford it.

## Assets

Prefer real or user-provided assets.

If unavailable:
- use honest placeholders;
- do not invent customers, screenshots, metrics, or testimonials;
- do not let decorative gradients substitute for missing product content.
