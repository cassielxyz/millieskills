# Millie UI Workflow

## Task sizing

### Small
Local component/style/state fix. Inspect local evidence, apply the smallest coherent change, verify.
Do not trigger full external research.

### Medium
New component/screen or meaningful interaction. Inspect product/design authority, choose intent mode,
load 2–4 references, implement, render representative states.

### Large / creative
Greenfield, redesign, brand-critical, scroll/3D, multi-screen native app, or unfamiliar category.
Use research locks, UX shaping, art direction, design system, implementation plan, motion/3D plan and
bounded verification.

## Phase graph

```text
CONTEXT
 -> UX / FLOW
 -> RESEARCH LOCKS (when warranted)
 -> ART DIRECTION
 -> DESIGN SYSTEM
 -> FUNCTIONAL STRUCTURE
 -> VISUAL BUILD
 -> MOTION / 3D
 -> HARDEN
 -> BATCH VERIFY
 -> FIX
 -> CONFIRM
```

Do not start with visual effects while the interaction model is unresolved.
