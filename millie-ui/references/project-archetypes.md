# Millie UI — Website & App Archetype Guide

Use this file to map product type to hierarchy, density, suitable styles, motion budget, and
common mistakes.

---

## Marketing / Website Archetypes

### SaaS / AI Product Landing
**Needs:** clear value, proof, product understanding, CTA
**Good styles:** refined minimal, technical precision, editorial SaaS, controlled glass, dark refined
**Motion:** demo reveal, product screenshot morph, small scroll scenes
**Avoid:** fake metrics, generic gradient blob, excessive 3D

### Corporate / B2B
**Needs:** trust, capability, navigation, evidence
**Good:** Swiss, refined minimal, editorial, heritage-modern
**Motion:** restrained
**Avoid:** agency-style chaos unless company brand supports it

### Creative Agency
**Needs:** identity, portfolio, confidence
**Good:** editorial, maximalist, anti-grid, neobrutalism, cinematic, WebGL narrative
**Motion:** medium/high
**Avoid:** hiding work behind effects

### Personal Portfolio
**Needs:** personality, work, contact, credibility
**Good:** almost any expressive style matched to creator
**Motion:** signature transitions, image interaction, optional 3D
**Avoid:** copying another famous portfolio one-to-one

### Ecommerce Store
**Needs:** discovery, product comparison, trust, transaction
**Good:** brand-led editorial, refined minimal, tactile/product-led
**Motion:** product hover, gallery transitions
**Checkout:** simplify aggressively
**Avoid:** decorative motion during payment

### Luxury / Fashion
**Needs:** desire, imagery, brand tone
**Good:** luxury minimal, editorial luxe, dark cinematic, Art Deco influence
**Motion:** slow controlled image/type choreography
**Avoid:** fake gold, over-decorated UI

### Restaurant / Food
**Needs:** appetite, menu, location, booking/order
**Good:** editorial, crafted, organic, heritage, bold graphic
**Motion:** food imagery reveal, subtle texture movement
**Avoid:** hiding hours/menu beneath spectacle

### Travel / Hospitality
**Needs:** inspiration + practical booking
**Good:** cinematic, editorial, organic, luxury minimal
**Motion:** image sequencing, map/space transitions
**Avoid:** video blocking booking access

### Real Estate / Architecture
**Needs:** imagery, spatial understanding, details, inquiry
**Good:** Swiss, editorial, luxury minimal, 3D showcase
**Motion:** plan/image transition, subtle spatial motion
**Avoid:** tiny property data

### News / Magazine / Blog
**Needs:** reading, scan, navigation, recirculation
**Good:** editorial, Swiss, refined minimal
**Motion:** low
**Avoid:** excessive card grids and infinite visual noise

### Documentation / Knowledge
**Needs:** search, hierarchy, reading, code
**Good:** monochrome precision, Swiss, developer utility
**Motion:** minimal
**Avoid:** marketing spacing and giant headings

### Event / Conference
**Needs:** identity, schedule, speakers, registration
**Good:** Bauhaus, neobrutalism, maximalist, editorial, retro-futurist
**Motion:** strong campaign motion allowed
**Avoid:** hiding date/location

### Nonprofit / Community
**Needs:** trust, mission, action
**Good:** organic, editorial, refined
**Motion:** low/medium
**Avoid:** luxury styling that conflicts with mission

### Government / Public Service
**Needs:** clarity, accessibility, task completion
**Good:** utilitarian, Swiss, refined minimal
**Motion:** minimal
**Avoid:** experimental navigation

### Cybersecurity Marketing
**Needs:** trust, technical credibility, product evidence
**Good:** data precision, dark refined, industrial, restrained spatial
**Motion:** data-flow motif, topology trace
**Avoid:** Matrix rain, green terminal cliché

### Gaming / Entertainment Site
**Needs:** atmosphere, content, fandom
**Good:** cinematic, retro pixel, Y2K, maximalist, 3D/WebGL
**Motion:** medium/high
**Avoid:** making navigation part of a difficult game unless intentional

## Application Archetypes

### Dashboard / Admin
**Needs:** scanability, filters, state, data, actions
**Density:** compact/balanced
**Good:** data precision, monochrome, industrial, restrained dark
**Motion:** low
**Avoid:** giant stat cards, decorative bento

### Productivity App
**Needs:** speed, focus, predictable workflows
**Good:** refined minimal, monochrome precision, soft neutral
**Motion:** functional state transitions
**Avoid:** excessive animation on frequent actions

### Developer Tool
**Needs:** density, keyboard, code/data hierarchy
**Good:** utilitarian, precision, dark refined, Swiss
**Motion:** fast, minimal
**Avoid:** fake terminal aesthetic if it isn't a terminal

### NOC / SOC / Security Console
**Needs:** alert hierarchy, dense telemetry, freshness, risk
**Good:** data precision, industrial, technical high-visibility
**Motion:** live state updates only
**Avoid:** glow overload, huge cards

### Finance / Banking
**Needs:** trust, clarity, amount precision, security
**Good:** refined minimal, Swiss, premium calm
**Motion:** restrained
**Avoid:** confusing gestures, pure neumorphism

### Healthcare
**Needs:** calm, trust, readable status, accessibility
**Good:** refined, organic-hybrid, soft neutral
**Motion:** restrained
**Avoid:** low contrast pastels

### Education
**Needs:** progress, comprehension, motivation
**Good:** friendly minimal, clay accents, organic, bold graphic
**Motion:** feedback/reward
**Avoid:** constant gamification motion

### Music / Audio
**Needs:** artwork, playback, tactile control
**Good:** modern skeuomorphism, dark cinematic, image-derived, chrome accent
**Motion:** waveform/progress, tactile controls
**3D:** optional album/visualizer scenes

### Video / Media
**Needs:** content dominance, controls
**Good:** dark cinematic, glass control layer
**Motion:** media transitions
**Avoid:** glass on content cards everywhere

### Messaging / Social
**Needs:** high-frequency interaction, presence, content
**Good:** clean balanced, image-derived accents, playful details
**Motion:** quick send/reaction feedback
**Avoid:** slow animated navigation

### Ecommerce App
**Needs:** discovery, cart, checkout
**Good:** brand-led clean system
**Motion:** product/card transitions
**Avoid:** surprise navigation in purchase flow

### Maps / Travel App
**Needs:** spatial context, controls, route info
**Good:** layered spatial, glass overlays, refined utility
**Motion:** map continuity, sheet transitions
**Avoid:** opaque panels hiding spatial context unnecessarily

### Smart Home / IoT
**Needs:** status, control, environment
**Good:** tactile/soft hybrid, refined, spatial
**Motion:** state feedback
**Avoid:** ambiguous neumorphic toggles

### Creative Tool / Editor
**Needs:** canvas dominance, pro controls
**Good:** utilitarian shell + expressive canvas
**Motion:** functional
**Avoid:** decorative toolbars

### Mobile Consumer App
**Needs:** touch comfort, clear navigation, identity
**Good:** platform-aware with brand accents
**Motion:** tactile, short
**Avoid:** web layout simply shrunk down

### Tablet Pro App
**Needs:** multi-pane, keyboard/pencil, density
**Good:** platform-native, precision
**Motion:** spatial pane transitions

### Desktop Professional App
**Needs:** menus, shortcuts, resizable panes
**Good:** compact utilitarian/refined
**Motion:** minimal

### Wearable
**Needs:** glanceability, tiny interaction, context
**Good:** platform-native
**Motion:** system-like
**Avoid:** decorative complexity

### Spatial / XR
**Needs:** spatial anchoring, depth, gaze/gesture
**Good:** system spatial materials, world-aware hierarchy
**Motion:** low sickness risk
**Avoid:** flat-web mental model copied into space
