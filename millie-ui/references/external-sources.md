# External Sources, Provenance & License

## Source hierarchy
1. official docs / official package;
2. upstream open-source repository;
3. established community registry;
4. independent installer/mirror with integrity evidence;
5. article/demo only as inspiration.

## Named sources Millie can use conditionally
- shadcn/ui — foundation and source registry ecosystem;
- SmoothUI / Unlumen UI / Animata / Animate UI — animated React source patterns;
- ThreeUI Community — open React/Three/WebGL components/assets;
- GSAP / Motion / Reanimated — motion engines;
- img2threejs — specialized image-to-procedural-Three reconstruction;
- Threlte / Theatre.js / Spline — creative 3D/motion stack;
- Refero / styles.refero.design / curated DESIGN.md libraries — research/taste references;
- Stitch — MCP-assisted screen/design-system loop;
- Agentation — structured visual feedback;
- brain.md — durable project decisions;
- Ruflo / Superpowers / Freebuff — process/orchestration context.

## Paid/pro boundaries
Do not scrape/copy premium implementation source just because its preview is public. If user has
legitimate access, use the provider's supported install/export path.

## Community component security
Third-party registry source can execute in the project. Review code, scripts, dependencies, remote
requests and assets before adopting. Prefer dry-run/diff/checksum features where available.

## Attribution
Preserve license notices/asset attribution when required. If origin is unclear, prefer implementing
the underlying idea independently rather than copying source.
