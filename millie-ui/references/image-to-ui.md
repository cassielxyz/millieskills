# Screenshot / Figma / Mockup to UI

## Separate evidence from inference

Evidence:
- visible hierarchy;
- spacing;
- color;
- typography clues;
- components;
- layout;
- iconography;
- state visible in image.

Unknown:
- hover;
- keyboard;
- error/loading;
- hidden navigation;
- mobile behavior;
- data model;
- animation.

Do not fabricate unknown behavior as though it was observed.

## Scaffold mode

If the user asks only for structure:
- produce semantic unstyled markup/component tree;
- preserve headings, landmarks, lists, forms, buttons, tables;
- do not add your own visual direction yet.

## Reconstruction mode

1. identify grid and content measures;
2. estimate typography roles;
3. derive tokens;
4. recreate component geometry;
5. use real assets if supplied;
6. implement accessible semantics;
7. add responsive adaptation;
8. add missing states using project conventions;
9. render beside the reference when tools allow;
10. correct large proportion/hierarchy differences first.

## Copyright / identity

Recreate user-provided/reference layouts only to the extent appropriate for the task.
Do not copy a third party's protected brand identity, logos, proprietary imagery, or exact creative
expression when the task can be satisfied through principles and an original implementation.
