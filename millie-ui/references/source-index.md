## Rule

A source appearing here does **not** mean Millie may copy it. Before adopting code/assets, check the
actual upstream license, edition (free/community/pro), current version, integrity/provenance, and the
user's legitimate access. Use proprietary showcases as inspiration only unless the user supplies
licensed source/export access.
