# Millie UI — Verification Reference

## Functional
- build
- lint
- typecheck
- relevant tests
- no UI-caused console/runtime errors

## Responsive
Inspect:
- narrow phone
- large phone
- tablet/narrow window
- laptop
- wide desktop when relevant
- intermediate widths around breakpoints

## States
- default
- hover
- focus-visible
- pressed
- selected
- disabled
- loading
- success
- warning/error
- empty/no-results
- long content
- missing media

## Accessibility
- semantic structure
- labels
- keyboard
- visible focus
- contrast
- target size
- reduced motion
- zoom/reflow
- touch/no-hover

## Premium Quality
Ask:
- Does the interface have a real art direction?
- Is it fit for this product?
- Is typography intentional?
- Is palette semantic and distinctive?
- Is spacing/proportion deliberate?
- Is there a memorable detail?
- Is that detail subordinate to usability?
- Is mobile intentionally composed?
- Does desktop use space intelligently?
- Does motion have purpose?
- Is 3D justified?

## Repetition Gate
Compare with known recent work:
- style
- layout
- palette
- typography
- material
- motion

If too similar without product reason, reroll one or more axes.

## Correction
Make one consolidated correction pass, then re-verify.
